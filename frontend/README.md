
# ChemShield AI 🧪

### Intelligent Chemical Compatibility & Laboratory Safety Platform

ChemShield AI is a React-based educational platform designed to help students explore chemical compatibility, understand laboratory hazards, learn chemistry concepts, and practise laboratory safety through an interactive interface.

The project combines a modern web interface with educational demonstrations for chemical safety awareness and chemistry learning.

## ✨ Features

- **Chemical Selection:** Select chemicals to explore compatibility information.
- **Safety Results:** View educational hazard information, precautions, personal protective equipment (PPE), and safety guidance.
- **Dashboard:** Access the platform's main features from one place.
- **Virtual Laboratory:** Explore demonstration experiments through an interactive interface.
- **AI Tutor:** Learn chemistry concepts using predefined demonstration responses.
- **Reports:** Explore sample report layouts and educational report information.
- **Responsive Design:** Use the platform on desktop, tablet, and mobile screens.
- **Light Theme:** Clean interface with a professional white, navy, and teal color palette.

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/MayankShakya07/ChemShield-AI.git
```

### 2. Open the project directory

```bash
cd ChemShield-AI/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

`http://localhost:5173`

### 5. Create a production build

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

## ⚠️ Important Limitations

ChemShield AI is currently an educational demonstration project.

- **Chemical safety:** Demonstration results must not be treated as verified chemical compatibility assessments or used as the basis for laboratory handling decisions.
- **AI Tutor:** The current tutor uses predefined responses and is not connected to a live AI model.
- **Virtual Laboratory:** The available experiments are demonstrations, not validated scientific simulations.
- **Authentication:** The current login interface is a frontend demonstration and does not provide secure, production-ready authentication.
- **Reports:** Displayed report content may contain sample or demonstration data.

Always consult authoritative Safety Data Sheets (SDS), approved laboratory procedures, and qualified laboratory personnel before working with chemicals.
